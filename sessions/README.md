# Sessions

One file per session, numbered in order. Each log records:

- **When:** the in-world date and time span.
- **What happened:** a short summary.
- **Key lines:** a few exact quotes worth keeping for continuity.
- **Inside:** Philip's thoughts, for continuity only (the firewall).
- **Established in play:** facts that became canon during the scene.
- **Open threads:** what's still hanging when the session ends.

The full back-and-forth lives in the chat. These logs are the record we check for continuity.
